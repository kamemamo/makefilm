| 項目 | 内容 |

## 1. 目的と方針

MakeFilm は、**フィルムが縦に流れる**操作感で素材を見て、印を付け、継いでいくための Mac 用カット編集アプリである。モデルは編集機ムービオラ。

- **役割分担**：カット編集（素材選び・IN/OUT・並べ替え）は MakeFilm、色・音・テロップなどの仕上げは Final Cut Pro / Premiere Pro / DaVinci Resolve で行う。そのため、元素材を参照するタイムラインを書き出せる（§9.2）。
- **見た目の語彙**：35mm フィルム、パーフォレーション、ゲート、グリースペンシル、スプライステープ、トリムビン、ペダル、エッジナンバーなど、フィルム編集の道具で UI を組み立てる。新機能もこの語彙に沿わせる。
- **正確さ**：再生・コマ送り・書き出しは AVFoundation を使い、フレーム単位で正確に扱う。

## 2. 動作環境

| 項目 | 内容 |

| CPU | Apple Silicon / Intel（配布版はユニバーサルバイナリ） |

### 言語
- 画面の文言は日本語と英語。macOS の言語設定に従い、日本語以外の環境では英語になる（開発言語 `en`、`CFBundleLocalizations` = en, ja）。
- コード中の文言は日本語で書き、`L("…")` で引く。英語は `mac/Localization/en.lproj/Localizable.strings`。数を含む文言は `%ld` / `%@` の書式で渡し、英語は複数形を避けた表現（例 `Cuts: %ld`）にする。

## 3. 用語

| 用語 | 意味 |
|---|---|
| 素材 | 読み込んだ動画ファイル 1 本 |
| リール | カットを順に継いだもの（編集結果） |
| カット（セグメント） | 素材の IN〜OUT の範囲 1 つ |
| ゲート | 今のコマが映る位置。縦フィルムの中央枠と、ビューアの映像部分 |
| スプライス | IN〜OUT をリールの末尾に継ぐこと |
| ストリップのコマ | 縦フィルム 1 コマ。動画の 1 フレームではなく「コマ密度」（6/12/24 コマ/秒）単位 |
| 流れ | フィルムが動く向き。上へ（標準）／下へ（ムービオラ式） |

├──────────┬─────────────────────────────────┬──────────┤
│ 縦フィルム │ ビューア（フィルム上のゲート）        │ 素材一覧   │

├──────────┴─────────────────────────────────┴──────────┤
│ 再生・編集ボタン（全幅）                                            │
├────────────────────────────────────────────────────────────┤
│ トリムビン（全幅・高さ 260pt・横スクロール）                         │

- ウィンドウ：既定 1360×920、最小 1100×760。単一ウィンドウ。配色はダークのみ。
- 通知（トースト）は再生ボタンの上に 1.8 秒表示。

### 4.1 ヘッダー
- ロゴの横に Info.plist のバージョン（`v0.1.0`）。`swift run` で起動した場合は出ない。
- モード切替：素材（`1`）／リール（`2`）。リールが空のときはリールに切り替えられない。
- 流れ：↑上へ（既定）／↓下へ。起動のたびに既定に戻る（保存しない）。
- コマ密度：素材と同じ（既定。縦フィルムの 1 コマ＝動画の 1 フレームで、←/→ で必ず 1 コマ動く）/ 6 / 12 / 24 コマ/秒。変えるとサムネイルを作り直す。「素材と同じ」はリール・素材の切り替えでフレームレートが変わると追従する。保存値は 0。
- 拡大：等倍（既定）/ 1.5× / 2× / 3× / 4×。縦フィルムの拡大率（§4.2.1）。
- 書き出し…（⌘E）：素材が 1 本以上あると有効。

### 4.2 縦フィルム（左）
- 35mm プリントフィルムの実寸比で描く（`Film35`、単位 mm を表示倍率で拡大）。フィルム幅 35・1 コマ 14.25（3 穴。16:9 の素材に合う送り方で、絵と絵がほぼ接して並ぶ）。
  - パーフォレーション：KS 型 2.794×1.981、ピッチ 4.75、フィルム端から 2.01 の位置（両側）
  - 光学サウンドトラック：左のパーフォレーションと絵の間（x 5.56〜7.59）。2 トラックのバイラテラル型（白い山が左右対称に広がる、§8.1）
  - パーフォレーションなし（`Film35.perforated = false`、このブランチの既定）：送り穴を描かない。コマの間隔は 3 穴と同じ 14.25。光学トラックは左端寄り（x 1.6、幅 3.0）に広げ、絵は 16:9 の 24.09×13.55 を x 5.45 から置く（16:9 の素材は切れない）。絵の右はフレームライン分（0.7）だけ残してフィルムを切るので、フィルム幅は 30.24。エッジのタイムコードは x 0.75。
  - 以下はパーフォレーションありのときの寸法。絵：21.0×13.55、x 7.8 から（中心よりやや右）。上下のフレームラインは細い 0.7。素材はこの枠いっぱいに縦横比を保って拡大し、はみ出した分を切る（黒帯は出さない。16:9 なら左右が少し切れる）。ビューアのゲートも同じ
  - フィルム幅は最大 180pt
- 停止中はゲート位置のコマを枠の中央にそろえる。手回し中・再生中は連続して動く。
- 中央がゲート（琥珀色のコーナー枠＋淡い光）。左端に再生位置の三角マーカー、帯の左に秒目盛り（`m:ss`）。
- コマの位置関係：流れが「上へ」なら後のコマが下、「下へ」なら後のコマが上。再生するとその向きに流れる。
- 素材の前後はリーダー（茶色の×印コマ）。素材の頭と終わりに琥珀色の線。
- 上下 12% は暗がりにフェード。右上に流れの向き（▲/▼）。
- 素材モード：IN/OUT にグリースペンシル風の波線と手書き風ラベル。波線はコマの間のフレームラインに引く（IN はそのコマの前＝前の素材との境、OUT はそのコマの後ろ＝次との境）。表示位置だけをストリップのコマにそろえ、編集点そのものは動画のフレーム単位のまま。右側の縦線は、IN と OUT が両方そろえば IN〜OUT に引かれる。片方だけのときは「描いている途中」として、その印からゲートのコマの端まで薄めの線を引き、先端に鉛筆の点を付ける。フィルムを送るとそれに合わせて線が伸び縮みする。
- リールモード：カットのつなぎ目に半透明のスプライステープ。

### 4.2.1 フィルムの拡大
- 縦フィルムの一部を拡大して見る。操作：ヘッダーの「拡大」、`Z`（等倍 ↔ 前回の拡大率、初回は 2×）、`+`（`=`・`;`）／`-` で 1 段ずつ、表示メニューの「フィルムを拡大」（⌘=）「フィルムを縮小」（⌘-）「フィルムを等倍に」（⌘0）、縦フィルム上でピンチ（指を離すと近い段にそろう）。前回の拡大率は保存する。
- 拡大すると縦フィルムの列が広がり、ビューアがその分右へずれる（0.28 秒のアニメーション）。ビューアには最低 380pt を残す。
- 拡大中は左端に全体のリール（細い縦フィルム。リール表示ではサウンドテープも並ぶ）が出る。拡大フィルムに映っている範囲を琥珀色の枠で囲み、枠の外を暗くし、枠の右上・右下から拡大フィルムの上端・下端へ点線を引く。全体のリールは秒目盛り・IN/OUT の文字・曲名を省く。
- 全体のリールも手回し・クリック・曲のドラッグができる（1 コマが小さいので速く送れる）。拡大フィルムでは 1 コマが大きいので細かく送れる。
- 列が広がりきらない（ウィンドウが狭い）ときは、絵のフィルムの拡大を優先し、サウンドテープを細くする（最小 56pt）。それでも入らない倍率では、フィルムを倍率どおりの大きさで描き、絵を中心に列の幅で切り取る（ルーペで覗く形。秒目盛りは列の左に残す）。

### 4.3 ビューア（中央）
- 映像は 1 本の 35mm プリント上の「ゲート」として、縦フィルムと同じ実寸比で描く（`FilmLayout`）。
  - 表示範囲：ゲートのコマ＋上下に 0.22 コマずつ（外側ほどフードの色に沈む）
  - ゲートの絵はアカデミー比の画面の位置。動画はその中に縦横比を保って収める
  - パーフォレーション、光学サウンドトラック、フレームラインは縦フィルムと同じ寸法
  - パーフォレーションの外側に、各コマの頭のタイムコード（`HH:MM:SS:FF`、素材のフレームレート）をエッジプリントとして縦書きで入れる
- 動き：
  - 停止中・手回し中：今のコマがゲートにぴったり収まる。
  - 再生中：映写機の爪のような**間欠送り**。各コマの前半 55% は静止し、残りでなめらかに 1 コマ送る。
- 映像には周辺減光（ビネット）、再生中はランプのかすかな揺らぎ。
- 素材がないときは「動画ファイルをここにドロップ」と「素材を開く…」。

### 4.3.1 サウンドリール（リール表示のとき）
- 縦フィルムの列が 400pt に広がり、絵のリールのすぐ右に音楽用の磁気テープ（パーフォレーションなし、全面が茶色の磁性面）が並ぶ。2 本は同じ速さで流れ、ゲートの位置（両端の琥珀色の目印）がそろう。
- 置いた音楽は、テープの中央に音声編集ソフトのような波形で描く：画面の 1 行（1px）ごとのピーク、中央線の左に負のピーク・右に正のピーク（× 音量・フェード）。ほぼ線形なので、とがったピークがそのまま見える。頭と終わりにグリースペンシルの線と「♪ 曲名」。
- 選んでいる曲は琥珀色の枠で囲む。
- 磁性面の上で曲をつかんで上下にドラッグすると、その曲を絵に対して前後にずらす（離すと動画のフレームにそろえる。取り消し可）。曲のないところをドラッグすると、これまでどおりフィルムの手回し。

### 4.4 素材一覧（右）
- 各素材：サムネイル（尺の 25% 地点）、ファイル名、尺（タイムコード）。クリックで素材モードに切り替えて表示。表示中の素材は琥珀色の枠。
- その下に「サウンドリール」の欄：「＋ 音楽を読み込む…」（⇧⌘I）、置いた曲の一覧（曲名・置いた位置・長さ。クリックで選んでその位置へ）。
- 曲を選ぶと設定欄が出る：音量（0〜150%、離したときに反映）、フェードイン／アウト（なし・0.5・1・2・3・5 秒、長さの半分まで）、「ゲートで切る」（⇧C）、「削除」（⌫）、「ゲートで頭を切る」「ゲートで終わりを切る」、「頭をゲートへ」（曲の頭をゲートの位置へ動かす）。
- 曲のカット：
  - ゲートで切る（⇧C、リール表示の「曲を切る」ボタンも同じ）：ゲートの位置で曲を 2 つに分ける。対象は、ゲートが選択中の曲の中にあればそれ、なければゲート位置の曲。フェードインは前の片に、フェードアウトは後ろの片に残し、後ろの片を選ぶ。端から 1 フレーム未満では切らない。
  - 外す（⇧X）：ゲート位置の曲（なければ選択中の曲）をサウンドリールから外す。
  - 削除（⌫ / Delete、右パネルの「削除」）：曲（の片）を選んでいるときは、その曲を削除し、空いたところを詰める（後ろにある曲がすべて削除した長さぶん前へ寄る。削除した曲の頭より前には動かない）。⇧X も同じく詰める。曲を選んでいなければ、これまでどおりゲート位置の絵のカットを外す。曲の選択は、サウンドテープ上の曲をクリック・右パネルの一覧・曲を切ったとき（後ろの片）に付き、絵のフィルムをつかむ・トリムビンのカードをクリック・素材表示に切り替えると外れる。
  - 切ってできた片は、それぞれドラッグでずらしたり、外したり、音量・フェードを変えたりできる。取り消し可。

### 4.5 再生・編集ボタン
- カウンター：タイムコード `HH:MM:SS:FF`（素材のフレームレートで丸めた NDF）、35mm フィート表示（24fps・3 穴。1 フィート 64 穴＝21⅓ コマで、「フィート+そのフィートの中のコマ」）。
- ◀︎|・▶︎/❚❚・|▶︎（1 フレーム）
- ペダル：◀4 ◀2 ◀1 ■ ▶½ ▶1 ▶2 ▶4（今の速度を強調表示）
- 素材モード：IN（`I`）、OUT（`O`）、スプライス（`⏎`）、現在の IN/OUT 表示
- リールモード：切る（`C`）、外す（`X`）、取り消し（`⌘Z`）

### 4.6 トリムビン（下・全幅）
- 上部のラックからカットがリール順に左→右へ吊るされる（幅 76pt）。
- **吊るす長さは尺に比例**：一番長いカットがビンの高さいっぱい。最低 1 コマ分。コマ数は長さに合わせて増減し、カット全体から等間隔に抜き出す。
- 各カット：番号、秒数、×（外す）。ホバーで素材名と IN–OUT。
- リール表示中は、ゲート位置のカットを琥珀色の枠で強調。
- クリック：リールモードに切り替えてそのカットの頭へ。
- ドラッグ＆ドロップ：カットの前に挿入して並べ替え。右端の空き領域へ落とすと末尾へ。⌥ を押しながらだと複製（§7）。
- スクロール：マウスホイールの縦回転で左右に動く（トラックパッドの横スワイプも可）。スプライスでカットが増えると右端まで自動スクロール。

## 5. データモデル

```text
MediaClip（素材）
  id, url, name, asset(AVURLAsset)
  duration, fps(nominalFrameRate, 0 のとき 24)
  displaySize（回転適用後）, naturalSize, preferredTransform
  videoTrack, audioTrack?
  markIn?, markOut?（秒）, lastTime（素材ごとの最後の位置）

Segment（カット）
  id, mediaID, start, end（素材内の秒。length = end - start）

Editor（アプリ状態）
  media[], reel[Segment], mode(.source/.reel), currentMediaID
  speed, direction(-1=上へ, 1=下へ), stripFPS(6/12/24)
  undoStack/redoStack（リールのスナップショット、最大 200）
  exportOptions（UserDefaults "exportOptions" に保存）
```

- **シーケンス**：素材モードでは「選択中の素材全体」を 1 カットとして、リールモードでは `reel` を扱う。再生位置はシーケンス上の秒で表し、`locate(t)` でどのカットの素材の何秒かに変換する。
- 保存と読み込みは §10「プロジェクト」を参照。

## 6. 再生とコマ送り

### 6.1 再生エンジン（`PlaybackEngine`）
- 1 台の `AVPlayer`。素材モードは素材の `AVPlayerItem`、リールモードはリール全体から作った `AVComposition`（§6.3）を再生する。
- 停止中・手回し中の再生位置はアプリ側の値で持ち、シークを後追いさせる（ゼロ許容のシーク。前のシークが終わるまで次を出さない）。そのため手回しは即座に反応し、映像は追いつき次第表示される。
- 再生中の位置は `AVPlayer.currentTime()`。終端で止まったらその位置を採用する。

### 6.2 速度
- ペダル：−4, −2, −1, 0, ½, 1, 2, 4 倍。
- `canPlayReverse` / `canPlayFastReverse` / `canPlayFastForward` が真ならネイティブ再生。偽なら毎フレーム手動でシークして動かす（音なし）。
- 終端から正方向に再生すると頭から、先頭から逆方向に再生すると末尾から始める。
- 停止すると、動画フレームの中央に揃える（スナップ）。

### 6.3 リールの合成（`ReelComposition`）
- 映像 1 トラック・音声 1 トラックの `AVMutableComposition` にカットを順に挿入。音声のない素材は映像のみ。音声が 1 つもなければ音声トラックを消す。
- 出力サイズ＝先頭カットの素材の表示サイズ（偶数に丸め）。他のカットは回転を適用して**アスペクト維持で収める**（レターボックス）。
- フレームレート＝先頭カットの素材。
- 再生と書き出しは同じ合成を使うので、カット境目でつっかえない。

### 6.4 操作一覧

| 操作 | 動作 |
|---|---|
| Space | 再生（1×）／停止 |
| L | 正方向。押すたびに 1→2→4 倍 |
| J | 逆方向。押すたびに −1→−2→−4 倍 |
| K | 停止 |
| ← / → | 1 フレーム戻す／送る（Shift で約 1 秒＝四捨五入した fps 分） |
| ↓ / ↑ | フィルムを下／上に送る（流れの向きに合わせて前後が決まる） |
| Home / End | 先頭／末尾 |
| I / O | IN／OUT（素材モード） |
| Return / Enter | スプライス（素材モード） |
| C | ゲート位置で切る（リールモード） |
| X / Delete | ゲート位置のカットを外す（リールモード） |
| 1 / 2 | 素材／リール |
| ⌘N / ⌘O / ⌘S / ⇧⌘S | 新規／プロジェクトを開く／保存／別名で保存 |
| ⌘I / ⇧⌘I / ⌘E / ⌘Z / ⇧⌘Z | 素材を読み込む／音楽を読み込む／書き出し／取り消し／やり直し |
| ⌘C / ⌘V | カットのコピー／貼り付け（§7） |
| ⇧C / ⇧X | ゲート位置で曲を切る／ゲート位置の曲を外す（リール表示） |

- キーは書き出し中・書き出し画面表示中は無効。⌘・⌃・⌥ 付きはメニューに任せる。

### 6.5 手回し（縦フィルム）
- ドラッグ：指の移動量 ÷ コマの高さ ÷ コマ密度 だけ進む／戻る。流れの向きに従う。
- 離す直前 80ms 以内に動いていれば惰性で流れ、毎フレーム 0.9 倍に減速して止まると動画フレームに揃える。
- 4pt 未満の移動はクリック扱い：クリックしたコマへ移動。
- スクロール：トラックパッドはそのまま、マウスホイールは 12 倍。止まって 0.2 秒後に揃える。

### 6.5.1 手回し中の音（スクラッチ）
- シーケンスの音声（素材モードは素材の音、リールは素材の音とサウンドリールを混ぜたもの）を、読み込み・編集のたびに裏で 32 kHz ステレオに展開してメモリに置く（`ScratchAudio`、30 分まで）。
- フィルムをドラッグ・スクロール・はじいて送っている間は、専用の音声エンジン（`AVAudioEngine` + `AVAudioSourceNode`）の再生ヘッドが、手の位置をサンプル単位で追いかける。
  - 前に送れば前に、戻せば**逆再生**で鳴る（レコードのスクラッチ、ムービオラでフィルムを前後に揺らすのと同じ）。
  - 音程は手の速さに比例（3 倍で 3 倍の高さ。最大 ±12 倍）。
  - 手が止まれば数ミリ秒で無音になる。音量の変化はなめらかにしてクリックを防ぐ。
  - ヘッドは約 40ms で手との差を詰め、速さは約 8ms でなじむ。1.5 秒以上の飛び（別の場所をクリックなど）はスクラッチせずに飛ぶ。
- この間、絵はこれまでどおりシークで追いかける。ペダルでの再生は AVPlayer のまま（音程は速さに合わせて変わる `varispeed`）。
- 音声の展開が終わるまでは、AVPlayer を手の速さで走らせる従来の方法で鳴らす（前向きのみ）。
- 表示メニュー「手回し中に音を出す」で切り替え（既定はオン、ユーザーごとに保存）。オフのときは音なし。

### 6.6 手回し（ビューア）
- 映像・前後のコマ・縁のどこでもスクロールで送れる（カーソルは上下矢印）。
- 縦スクロールは縦フィルムと同じ向き、横スワイプは左で先へ。
- マウスホイール 1 目盛り＝1 フレーム。トラックパッドは約 6pt で 1 フレーム。止まって 0.2 秒後に揃える。

## 7. 編集

| 操作 | 仕様 |
|---|---|
| IN | 今の動画フレームの頭。OUT 以降なら OUT を消す |
| OUT | 今の動画フレームの終わり（そのフレームを含む）。IN 以前なら IN を消す |
| スプライス | IN（なければ 0）〜OUT（なければ素材の終わり）をリール末尾へ。1 フレーム未満は不可。成功すると IN/OUT を消す |
| 切る | ゲートのコマの直前でカットを 2 つに分ける。両側とも 1 フレーム以上必要 |
| 外す | ゲート位置のカット（またはビンの ×）をリールから除く。位置はそのカットの頭へ |
| 並べ替え | トリムビンのドラッグ＆ドロップ |
| 複製 | トリムビンで ⌥ を押しながらドラッグ＆ドロップすると、移動せずにコピーを差し込む（ドロップ位置の印が緑と「+」になる） |
| コピー（⌘C） | リール：ゲート位置のカット。素材：IN（なければ 0）〜OUT（なければ終わり）。アプリ内のクリップボードに保持し、システムのクリップボードは使わない |
| 貼り付け（⌘V） | リール：ゲート位置のカットのすぐ後ろに差し込み、ゲートをそこへ移す。素材表示中：リールの最後に追加。何度でも貼り付け可能（毎回新しいカットになる） |
| 取り消し／やり直し | リールの変更（スプライス・切る・外す・並べ替え・複製・貼り付け）が対象。最大 200 段 |

- リールの絵も音楽も空になったら素材モードに戻る。
- 素材ごと・リールごとに最後の再生位置を覚え、切り替えたときに戻す。

## 7.1 サウンドリールのデータと再生
- 音声ファイル（`AudioSource`：mp3・m4a・aac・wav・aif・caf・flac）と、それをリールに置いた曲（`MusicClip`：使う範囲 start〜end、リール上の位置 at、音量 gain、fadeIn / fadeOut）。曲同士は重なってもよい。
- 読み込み（⇧⌘I、ドロップ、Finder から開く）はリールが空でもできる（音楽を先に置いて、絵を合わせて継げる）。リール表示中はゲートの位置から、素材表示中は前回のリールの位置から順に置き、リール表示に切り替える。読み込むとサウンドトラックと同じ方法で波形を解析する。
- 再生と書き出し：リールの `AVComposition` に曲ごとの音声トラックを足し、`AVAudioMix` で音量とフェードを付ける。再生では音楽の終わりまでリールが続き、絵のないところは黒（音楽だけのリールも可）。書き出しでは絵の終わりで切る（その場合、終わりのフェードはかからない）。書き出し範囲が「素材の IN〜OUT」のときは音楽を含めない。
- 取り消し／やり直しは、リールとサウンドリールを一緒に戻す。
- プロジェクトファイルに `musicSources`（素材と同じ形式：絶対パス＋相対パス）と `music` を保存。見つからない音声ファイルは場所を尋ね、キャンセルするとその曲を外す。古いプロジェクト（0.4 以前）も読める。

## 8. サムネイル

- `AVAssetImageGenerator`（最大 240×240、回転適用、許容誤差 ±0.4/コマ密度 秒）で、ストリップのコマ単位（素材秒 × コマ密度）に生成。
- 縦フィルムが毎フレーム、画面内のコマ＋前後 24 コマ（再生中は進行方向のみ）を要求。**ゲートに近いコマから**順に作る。
- トリムビン・素材一覧・ビューアの前後のコマは「保持要求」として登録し、できたら再描画する。
- キャッシュは最大 4000 枚（古いものから捨てる）。コマ密度を変えると全て作り直す。

### 8.1 サウンドトラック（音声の波形）
- 素材を読み込むと、裏で音声を一度読み（24 kHz に変換）、1/240 秒ごとのピーク値をチャンネル別（最大 2、5.1 などはステレオにまとめる）に保持する（`AudioEnvelope`）。20 秒の素材で 0.3 秒ほど。サウンドリールの音楽は細かい波形用に、1/4000 秒ごとの正と負のピーク（チャンネルをまとめて）を、ほぼ線形（0.85 乗）で保持する。
- 表示用に、素材内の最大値で正規化し、0.6 乗して小さな音も見えるようにする。
- 描画は左右対称の帯（バイラテラル型）。無音はごく細い線、音が大きいほど太い。ステレオは左右 2 本、モノラルは 2 本とも同じ。
- 音と絵は同じコマに並べる（実際のプリントのように 20 コマずらすことはしない）。
- 解析が終わるまでは細い線だけが表示される。

## 9. 書き出し（⌘E）

書き出し画面で **範囲・形式・サイズ** を選ぶ。選んだ内容は次回も残る。下部に長さ・カット数・出力サイズ・拡張子の要約。

### 9.1 範囲
- **リール全体**、または**素材の IN〜OUT**（スプライス不要。印がなければ素材全体）。
- 静止画は範囲ではなく「ゲートにある今のコマ」。

### 9.2 形式

| 形式 | 拡張子 | プリセット／方式 | サイズ |
|---|---|---|---|
| H.264（MP4） | .mp4 | HighestQuality / 3840x2160 / 1920x1080 / 1280x720 | 元・4K・1080p・720p |
| HEVC / H.265 | .mov | HEVCHighestQuality / HEVC3840x2160 / HEVC1920x1080 | 元・4K・1080p |
| Apple ProRes 422 | .mov | AppleProRes422LPCM | 元のみ |
| Apple ProRes 4444 | .mov | AppleProRes4444LPCM | 元のみ |
| 音声のみ（AAC） | .m4a | AppleM4A（音声がなければエラー） | — |
| 静止画（PNG） | .png | ゼロ許容で今のコマを取り出し PNG 保存 | 元 |
| Final Cut Pro | .fcpxml | FCPXML 1.10 を生成 | — |
| Premiere Pro | .xml | Final Cut Pro 7 XML（xmeml v4）を生成 | — |

- サイズ指定は**縮小のみ**（小さい素材は拡大されない）。要約表示もその前提で計算する。
- 動画の書き出しは `AVAssetExportSession`。進捗バーと中止ボタンを表示し、完了したら Finder で選択表示する。
- 既定のファイル名：`MakeFilm リール` または素材名＋形式名（例 `_ProRes422`、`_1080p`、静止画はタイムコード付き）。

### 9.3 編集ソフト向けタイムライン（FCPXML / xmeml）
- **元の素材ファイルを参照**する。映像は書き出さないので劣化も待ち時間もない。書き出し後に素材を動かすとリンクが切れる。
- 保持する情報：カット順、各カットの IN/OUT、音声（有無・チャンネル数・サンプルレート）、素材の解像度・フレームレート。
- フレームレートは有理数で表す：整数 fps は `100/(fps×100)s`、23.976 / 29.97 / 59.94 などは `1001/(fps×1000)s`。
- 素材のタイムコードトラック（例 01:00:00:00 開始）を読み取り、FCPXML の asset `start` と各クリップ `start`、xmeml の `<timecode>` に反映する。
- シーケンスの設定は先頭カットの素材に合わせる。各カットの長さはシーケンスのフレームに丸める。
- FCPXML：`resources`（format・asset＋`media-rep`）→ `library/event "MakeFilm"/project/sequence/spine/asset-clip`。Final Cut Pro 同梱の DTD（v1.10）で妥当性を確認済み。
- サウンドリール：FCPXML では、曲の頭がある絵のクリップに `lane="-1"` の接続クリップ（`audioRole="music"`）として付け、音量は `adjust-volume`（dB）、フェードは `fadeIn` / `fadeOut`。xmeml では 2 本目の音声トラックに置き、音量は Audio Levels フィルタ（フェードは渡さない）。どちらも絵の終わりで切る。
- xmeml：映像トラック 1・音声トラック 1（＋音楽トラック）、`clipitem` の `in/out` は素材頭からのフレーム数、`start/end` はシーケンス上のフレーム数。映像と音声は `link` で結ぶ。

## 10. プロジェクト

### 10.1 ファイル形式
- 拡張子 `.makefilm`（UTI `local.makefilm.project`、JSON に準拠）。中身は整形済み JSON。素材ファイル自体はコピーしない。

```json
{
  "format": "makefilm-project", "version": 1,
  "media": [{ "id": "…", "path": "/絶対パス/clip.mov", "relativePath": "clips/clip.mov",
              "markIn": 2.0, "markOut": 4.04, "lastTime": 7.0 }],
  "reel": [{ "id": "…", "mediaID": "…", "start": 2.0, "end": 4.04 }],
  "currentMediaID": "…", "mode": "source", "reelTime": 0,
  "direction": -1, "stripFPS": 12
}
```

- 保存するもの：素材（ID・絶対パス・プロジェクトからの相対パス・IN/OUT・最後の位置）、リール、表示中の素材とモード、リールの位置、流れの向き、コマ密度。
- 保存しないもの：取り消し履歴、書き出し設定（アプリ全体で 1 つ）。

### 10.2 操作
| メニュー | 動作 |
|---|---|
| 新規プロジェクト（⌘N） | 未保存なら確認してから空にする |
| プロジェクトを開く…（⌘O） | 未保存なら確認してから開く |
| 最近使ったプロジェクト | 最大 8 件。存在しないものは表示しない。履歴を消去できる |
| 保存（⌘S） | 未保存の新規なら保存先を尋ねる |
| 別名で保存…（⇧⌘S） | 新しい場所に保存し、以後そのファイルを編集する |
| 素材を読み込む…（⌘I） | 動画を素材に追加（同じファイルは二重に読み込まない） |

- Finder で `.makefilm` をダブルクリック／Dock アイコンやウィンドウへドロップでも開ける。動画をドロップすると素材に追加。
- 起動時、ほかに開くものがなければ前回のプロジェクトを自動で開く。

### 10.3 編集済みの判定
- 「素材の一覧・パス・IN/OUT」と「リール」が最後に保存（または開いた）状態と違えば編集済み。再生位置・流れの向き・コマ密度の変更だけでは編集済みにならない（保存時には一緒に書く）。
- ウィンドウのタイトルは「プロジェクト名」、編集済みなら「— 編集済み」が付く。新規は「名称未設定」。
- 編集済みのまま終了・ウィンドウを閉じる・新規・別のプロジェクトを開くときは「保存／キャンセル／保存しない」を尋ねる。

### 10.4 素材が見つからないとき
1. 保存した絶対パス → 2. プロジェクトファイルからの相対パス の順に探す（フォルダごと移動しても開ける）。
2. どちらにもなければ、素材ごとに場所の指定を求める。キャンセルした素材はプロジェクトから外し、それを使うカットも外して、一覧を知らせる。
3. 場所が変わった・外した素材がある場合は、開いた直後から編集済みにして、保存で新しい場所を書き込めるようにする。

## 12. ビルドと配布

```bash
cd mac
./scripts/build-app.sh               # この Mac 向け release ビルド
./scripts/build-app.sh debug         # debug ビルド
./scripts/build-app.sh --universal   # 配布用（arm64 + x86_64、最小 macOS 14）
```

- `swift run MakeFilm <動画ファイル>` でも起動でき、引数の動画を素材として読み込む。
- 署名はアドホック。公証していないため、配布版は初回起動時に Gatekeeper の警告が出る（システム設定 → プライバシーとセキュリティ → 「このまま開く」）。
- リリース手順：`Info.plist` のバージョンを上げる → `--universal` でビルド → `ditto -c -k --keepParent build/MakeFilm.app MakeFilm-<版>-macOS.zip` → SHA-256 を添えて GitHub Releases（タグ `v<版>`）に登録。

## 13. 制約と既知の課題

| 区分 | 内容 |
|---|---|
| 保存 | 取り消し履歴はプロジェクトに保存しない。自動保存はない（終了時に確認する） |
| 編集 | 音声のレベル調整・フェード・クロスフェード、トランジション、テロップ、複数トラックはない（仕上げは他ソフトに渡す前提） |
| 混在素材 | リールは先頭カットのサイズ・フレームレートに合わせる。フレームレートの違う素材を混ぜると、編集ソフト向け XML の長さはシーケンスのフレームに丸められる |
| タイムコード | ドロップフレームも NDF 表記で扱う |
| 書き出し | サイズ指定は縮小のみ。ProRes / 音声 / 静止画はサイズを選べない |
| 表示 | ウィンドウが画面に出ていない（別デスクトップのフルスクリーンなど）と、ビューアのアニメーションは止まる |
| 配布 | 公証なし（Apple Developer Program 未加入） |
| 未検証 | FCPXML / XML を各編集ソフトに実際に読み込む確認は利用者側で行う段階 |
